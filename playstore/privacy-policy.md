# Shobu Privacy Policy

**Effective date:** 20 November 2026

Shobu is an offline, local two-player board game. It does not create accounts, connect to a server, show advertisements, use analytics, or collect or transmit personal information.

The app does not request sensitive Android permissions. The current theme choice is stored on the device using Android preferences. Game positions are held only while the app is running and are not uploaded or shared.

If a future version adds online features or changes what data it handles, this policy will be updated before that version is released.

For privacy questions, contact the developer using the support email shown on the Shobu Google Play listing.
